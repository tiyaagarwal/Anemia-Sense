Leakage-aware CBC analytics & anemia classification

A machine learning system that classifies anemia-related conditions from a full Complete Blood Count (CBC) panel — not a single lab value. Built after diagnosing and fixing a data-leakage bug in an earlier version that made the problem trivially easy for a model to "solve."

How the pipeline works

1. Data quality

Every training run deduplicates the dataset and rejects physiologically impossible values (e.g. negative hemoglobin) before anything touches a model. See the full report on the Data & Methodology page.

2. Benchmarking

Five classifiers are compared via stratified 5-fold cross-validation, scored on macro-F1 (not raw accuracy) because the classes are imbalanced. The winner is tuned with RandomizedSearchCV, still without ever touching the held-out test set.

3. Explainability

Every prediction ships with the specific CBC values that drove it (SHAP), plus a model-wide feature importance ranking (permutation importance) computed on the held-out set — not the training set.

Key capabilities

Multi-class CBC classification

Predicts across 9 real diagnostic categories present in the source data (Healthy, Iron deficiency anemia, Macrocytic anemia, Leukemia, Thrombocytopenia, and more) — not a coin-flip binary label.

Model transparency

The Model Performance page renders the actual cross-validation and held-out test metrics from reports/metrics/latest_metrics.json — nothing on that page is hardcoded.

REST API

POST /api/v1/predict accepts the same 14 CBC values as JSON and returns a prediction, confidence, and top contributing features — for programmatic use, not just the web form.

Honest about its limits

The Data & Methodology page documents exactly why an earlier version of this project reported ~100% accuracy, and why that was a red flag rather than a result.
