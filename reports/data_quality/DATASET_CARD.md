# Dataset Card — Anemia Types Classification (CBC)

## Source

- **Original dataset:** [Anemia Types Classification](https://www.kaggle.com/datasets/ehababoelnaga/anemia-types-classification) by Ehab Aboelnaga, Kaggle.
- **License:** Apache 2.0.
- **Description (from the dataset page):** "CBC data labeled with the diagnosis of Anemia type, the data collected among several CBCs data and diagnosed manually."
- **Local copy:** `data/raw/anemia_types_cbc.csv`, retrieved via a public GitHub mirror ([BhaveshBhakta/Anemia-Type-Prediction-Using-ML](https://github.com/BhaveshBhakta/Anemia-Type-Prediction-Using-ML)) because downloading directly from Kaggle requires an authenticated account. The mirror was verified to match the Kaggle dataset card exactly on row count (1281), column names, and description before being used here. Apache 2.0 permits this redistribution with attribution, which this card provides. Anyone with a Kaggle account can re-download the canonical file via `kaggle datasets download ehababoelnaga/anemia-types-classification` for byte-for-byte provenance.

## Schema

1281 rows × 15 columns: `WBC, LYMp, NEUTp, LYMn, NEUTn, RBC, HGB, HCT, MCV, MCH, MCHC, PLT, PDW, PCT, Diagnosis`.

`Diagnosis` (target, 9 classes): Healthy, Iron deficiency anemia, Normocytic hypochromic anemia, Normocytic normochromic anemia, Other microcytic anemia, Macrocytic anemia, Thrombocytopenia, Leukemia, Leukemia with thrombocytopenia.

## Audit findings (see `reports/data_quality/data_quality_report.json` for the machine-readable, reproducible version — generated by `src/data/validate_data.py`)

- **Duplicates:** 49 of 1281 rows (3.8%) are exact duplicates — removed before any split. Far lower than the 62% found in the original single-feature dataset this project started with, but still a real, necessary cleaning step.
- **Missing values:** none.
- **Physiologically implausible values:** 33 of the remaining 1232 rows (2.7%) contain at least one value outside generous adult reference ranges (e.g. MCV of 990 fL, HGB of -10 g/dL, MCHC of 92.8 g/dL — all impossible for a living patient). These read as data-entry corruption (decimal-place or digit-transposition errors), not genuine extreme pathology. Rows are dropped rather than imputed, since a corrupted value can't be reliably corrected. See `src/data/validate_data.py` for the exact per-column bounds used and their clinical justification.
- **Class balance:** imbalanced — Healthy (319) and the two Normocytic categories (250–262) dominate; Macrocytic anemia (16) and Leukemia with thrombocytopenia (10) are small. This is handled with stratified cross-validation and macro-averaged metrics (not raw accuracy) for model selection — see `reports/metrics/`. Per-class metrics for the two smallest classes should be read with wide uncertainty in mind; there are single-digit counts of them in any given test fold.
- **Single-feature leakage check:** a depth-1 decision tree stump on any individual feature tops out at 48.5% accuracy (HGB); even a depth-3 stump maxes out at 62.1%. No feature reconstructs the label the way Hemoglobin alone did in the original dataset (see `../../analysis/FINDINGS.md` for that history). The full 14-feature panel gets a Random Forest to ~98% accuracy / ~92% macro-F1, so the signal is real, but it requires the whole CBC panel, not one shortcut feature.

## Final row count after cleaning

1281 raw → 1232 after deduplication → 1199 after dropping physiologically implausible rows.
